# poulet-pt-front

Interface React + TypeScript (Vite) de gestion d'élevage de poulets de chair.

## Démarrage

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run lint
```

En développement, les appels à `/api` sont redirigés vers le backend (`http://localhost:4000`), voir `vite.config.ts`.
